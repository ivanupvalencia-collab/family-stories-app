Fuentes variables originales incluidas para uso offline, sin descargas en runtime:

- Lora: https://github.com/google/fonts/tree/main/ofl/lora
- Nunito Sans: https://github.com/google/fonts/tree/main/ofl/nunitosans

`Lora.ttf` es el original `Lora[wght].ttf` de Google Fonts (eje de peso
400–700), registrado en `pubspec.yaml` con los pesos utilizados: 500 y 600.
Nunito Sans conserva su archivo y configuración existentes.

Se incluyen las licencias originales SIL Open Font License en los archivos `*-OFL.txt`.
